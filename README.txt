PATEL INFOTECH - COMPUTER PARTS GUIDE
======================================

PROJECT
- React + TypeScript + Vite
- English / Hindi language switch
- Information-only website (no shopping/cart/payment)
- Responsive desktop, tablet and mobile layout
- Original PATEL INFOTECH PI logo included as public/pi-logo.jpeg
- Six cable guide cards with locally stored SVG illustrations
- Search, detail popups, contact phone and address

RUN ON WINDOWS
1. Extract this ZIP.
2. Open the extracted PATEL-INFOTECH-WEBSITE folder in VS Code.
3. Open Terminal > New Terminal.
4. Run: npm.cmd install
5. Run: npm.cmd run dev
6. Open the Local URL shown by Vite, usually http://localhost:5173/

BUILD FOR DEPLOYMENT
Run: npm.cmd run build
The production website will be created in the dist folder.

IMPORTANT CONTENT NOTE
The item "Vijay Cord" is shown exactly as supplied. Its technical identity is marked for confirmation because this is not a commonly identifiable standard cable name. If VGA cable was intended, update the item after confirming.
Printer Cord details distinguish printer power cords from USB printer data cables.
